# Каталог закладок ИИ

Автоматический Markdown-экспорт коллекции Raindrop 75570126 и её подпапок

После первого успешного запуска появятся:
- `bookmarks-ai.md`: полный каталог с описаниями, заметками и тегами
- `index.md`: краткий указатель по папкам

## Запуск

1. Создать публичный репозиторий `ai-bookmarks` и загрузить файлы этого комплекта, включая `.github/workflows/sync.yml`
2. В https://app.raindrop.io/settings/integrations создать приложение и скопировать Test token
3. В GitHub открыть Settings → Secrets and variables → Actions → New repository secret
4. Имя секрета: `RAINDROP_TOKEN`, значение: Test token из Raindrop
5. Открыть Actions → Sync AI bookmarks → Run workflow
6. После успешного запуска открыть `bookmarks-ai.md` и нажать Raw: эту ссылку передавать ИИ

## Поведение

Запуск запланирован ежечасно на 23 минуте UTC, возможны задержки GitHub Actions

Скрипт делает только GET-запросы к Raindrop, получает метаданные подпапок для восстановления дерева, но выгружает закладки только из разрешённого дерева

Сам токен не ограничен этой папкой: ограничение реализовано кодом экспорта

При ошибке, несовпадении количества или обнаружении чужой папки публикация не выполняется, предыдущий каталог сохраняется

Добавления, правки, перемещения и удаления отражаются при следующем успешном запуске. Прежние версии остаются в истории публичного Git-репозитория

Заметки копируются из Raindrop. Новые описания и звёзды GitHub автоматически не генерируются

Расписание не гарантирует обновление строго вовремя. В публичных репозиториях GitHub может отключить расписание после 60 дней отсутствия активности; проверяйте дату обновления и статус Actions
